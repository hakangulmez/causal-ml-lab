# C1 design — draft for review

Question: How do staggered timing, heterogeneous effects and flexible confounding adjustment change causal estimates? These are original demonstrations and a published-data replication. No thesis repository, code, text or figures are accessed or reused. Germany's minimum-wage regional application is future work.

Data: seeded balanced panels and partially linear nonlinear DGPs; `mpdta` from `did` 2.3.0 (500 counties, 2003–2007, 2,500 county-years; the installed older help count is stale); public 1991 SIPP 401(k) extract through `DoubleML.datasets.fetch_401K`. Private runtime downloads only. User approves analysis of SIPP; its redistribution scope is unverified, so no raw rows in Git or exports. Cite Callaway–Sant'Anna (2021), Chernozhukov et al. (2018) and DoubleML.

DiD: 100 Monte Carlo repetitions with staggered adoption, heterogeneous dynamic effects, never-treated controls and no anticipation. Compare TWFE, group-time CS and Sun–Abraham; fixed seed and balanced DGP, compare estimators on an explicitly aligned treated-person-time ATT. Use `fixest::sunab` as approved dCDH fallback. Goodman–Bacon 2×2 decomposition via `bacondecomp` if available. `mpdta`: TWFE vs CS group-time and dynamic ATTs, county-cluster influence-function inference. HonestDiD relative-magnitude bounds for the event-study impact when estimable; report sparse leads and normalization. Continuous-dose simulation distinguishes ATT at a given dose from a causal derivative (ACRT), with stated selection on gains.

DML: 100 repetitions, many controls and nonlinear confounding; OLS, in-sample ML residualization and cross-fitted orthogonal PLR score, bias/RMSE/nominal 95% coverage. 401(k): outcome net financial assets, eligibility `e401`, nine published covariates; PLR and IRM using Lasso, RF and gradient boosting; five folds, seed, one repetition, no outcome-based tuning. OLS baseline uses heteroskedasticity-robust inference. Causal forest CATE by pre-treatment income; held-out BLP calibration and independently held-out quartile AIPW summaries, with honest caveats on overlap, confounding and selection. No arbitrary trimming to improve results.

Outputs: aggregate CSV/Markdown estimates, simulation uncertainty, 300-dpi figures/PDFs, a two-page policy note, original theory drafts, README with self-audit and source/cost manifests. Own local Python/R environments. Offline synthetic `make quick`; full runtime acquisition in `make all`. No paid API calls. Risks: small number of treated cohorts, weak pretrend information, different DiD aggregation estimands, learner sensitivity, propensity overlap and initially uninstrumented R coverage (resolved by isolated covr checks at release). Minimum first: both Monte Carlos, mpdta CS/TWFE and real-data DML; optional failures remain explicitly incomplete.
